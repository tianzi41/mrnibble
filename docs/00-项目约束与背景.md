## 1. 项目目标

复刻 **Hyperknow**（面向大学生的 AI 学习平台，https://www.hyperknow.io/）的主要功能。

- 原软件按 100 分计，复刻版**验收目标 ≥ 70 分**。
- 交付物：**可下载即用的 Windows 桌面软件**（免安装绿色包），用户填入 API Key 后即可使用。

## 2. 用户已确认的四项决策（不可更改）

| 项 | 决策 | 含义 |
|---|---|---|
| 使用形态 | **单机单人** | 无需注册/登录；数据全部存本机；不做多用户权限隔离 |
| 交付方式 | **免安装绿色包** | 下载压缩包 → 解压 → 双击启动；不依赖开发者环境；不要求用户装 Docker / Python / Node |
| 功能范围 | **核心八件套** | 见第 4 节，不做代码沙盒 / 教学视频生成 / LMS 接入 |
| 运行平台 | **仅 Windows** | Windows 10 / 11 x64 |

## 3. 用户对语音的明确要求

- **TTS（朗读软件生成的文字）**：**可选**。
  - 可以不启用（默认关闭）。
  - 可使用**云端 API**（用户自己填语音 Key）。
  - 可使用**本地自带**能力。
- **ASR（学生说话 → 文字）**：**必须本地**。不调用云端 ASR。

## 4. 功能范围（核心八件套）

1. **文档上传与解析**：PDF / DOCX / PPTX / MD / TXT / 网页，至少 5 种格式；支持长文档（目标 1000 页）。
2. **基于材料的问答 + 引用溯源**：答案带页码/章节，可点击跳转；材料内问题准确回答，材料外明确说"未提及"。
3. **学习资料生成**：速查表（Cheatsheet）、学习笔记、思维导图、练习题（Quiz）、闪卡（Flashcard）。
4. **导出**：闪卡导出 Anki / Markdown / CSV；思维导图导出 Markdown / 图片。
5. **长期记忆**：跨会话记住学习进度与偏好；可查看 / 编辑 / 删除 / 导出。
6. **引导式教学**：不直接给答案；首轮给追问与拆解步骤；识别并记录知识盲区。
7. **本地语音识别（ASR）**：学生语音输入转文字，纯本地。
8. **可选语音朗读（TTS）**：关闭 / 本地系统语音 / 云端 API 三选一。

## 5. 硬性质量红线（一票否决，源自验收标准）

- ❌ API Key 不得写入日志、不得明文上传、不得下发到前端。
- ❌ 用户上传的文档不得在未经授权的情况下发送到第三方。
- ❌ 核心功能不得依赖开发者服务器（必须本机自洽运行）。
- ❌ 引用页码不得伪造；不得把材料外内容伪装成材料内内容。
- ❌ 长期记忆必须可删除，且删除后不得再被召回。
- ❌ 必须能切换自己的 API / 本地模型。
- ❌ 断网后本地模型模式必须可用。
- ❌ 构建必须成功，干净环境必须能启动。

## 6. 技术选型约束

- **尽量使用开源件，避免重复造轮子**（用户明确要求）。
- **默认技术栈**（架构师可微调，但须保持"绿色包可打包"这一前提）：
  - 后端：Python 3.11+（FastAPI），本机侧车服务
  - 前端：静态 Web UI（本地资源，不依赖 CDN）
  - 存储：SQLite（单文件，便于备份/迁移）+ 轻量向量检索
  - LLM：OpenAI 兼容协议（可指向 OpenAI / DeepSeek / 智谱 / 百炼 / SiliconFlow / Ollama / vLLM 等）
  - 嵌入：OpenAI 兼容 `/embeddings`；提供本地嵌入兜底
  - 文档解析：pypdf / python-docx / python-pptx / BeautifulSoup 等开源库
  - ASR：本地离线模型（如 faster-whisper / sherpa-onnx 一类，可从 pip 安装）
  - TTS：本地系统语音（浏览器 SpeechSynthesis）+ 云端 OpenAI 兼容 `/audio/speech`
  - 导出：Anki `.apkg`（genanki）、CSV、Markdown、思维导图（markmap）
