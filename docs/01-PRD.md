## 1. 产品目标

**一句话定位**：知伴是一款**单机单人的本地 AI 学习助手**——学生把自己的课件、论文、教材放进本机，即可基于**自己的材料**提问、生成复习资料、被"像老师一样"引导式教学，全程数据不出本机。

### 成功指标（把"70 分"拆成可检查条目）

复刻达标线：下列 5 项合计 100 分，**实测得分 ≥ 70 分**视为通过。

| 编号 | 指标 | 满分 | 可检查判据 |
|---|---|---|---|
| M1 | 材料闭环可用 | 40 | 能完整走通「上传 → 解析 → 问答 → 引用 → 生成五类资料 → 导出」；覆盖 ≥5 种格式；长文档 1000 页不崩溃 |
| M2 | 引用与材料边界严谨 | 15 | 引用页码真实可跳转；材料内基准题正确率 ≥80%；材料外问题明确回"未提及"且不编造引用 |
| M3 | 引导式教学成立 | 20 | 首轮不给最终答案、必须含追问与拆解步骤、能识别并记录知识盲区（三条均通过） |
| M4 | 本地语音与长期记忆可用 | 15 | 断网下本地 ASR 可录音转文字；跨会话记忆生效且可查看/编辑/删除 |
| M5 | 交付与隐私护栏 | 10 | 一键构建成功；干净 Windows 环境解压双击可启动；Key/数据不出本机；记忆删除后不可召回；断网本地模型可用 |

**北极星约束**：任何一票否决红线（见第 5 节）触发即整体判定不通过，与得分无关。

## 2. 目标用户与核心场景

**目标用户**：单机单人使用的**大学生 / 自学者**，Windows 10 / 11 x64 用户，熟悉自行填写 API Key，重视隐私（不希望把课程材料传到第三方服务器）。

**核心使用场景**：

1. **期末 3 天速成一门课**：把整学期 PPT + 讲义一次性上传，生成速查表与复习笔记，再把重点做成闪卡导出 Anki，碎片时间反复刷。
2. **读一篇 40 页论文并提问**：上传 PDF，直接问"作者的核心论点是什么""这个方法在材料里怎么定义"，答案带页码可点击跳回原文；问到材料里没有的，系统明确说"材料中未提及"。
3. **用语音问一道题**：手上有草稿不方便打字时，按住说话"这道积分题该怎么想"，本地 ASR 转成文字，系统进入引导式教学：先反问与拆解，不直接给答案。
4. **自学一个新领域搭认知地图**：上传多份资料，先生成思维导图、建立整体框架，再跟着引导路径一个一个知识点推进，答错的地方被记为知识盲区。
5. **考前查漏补缺**：打开记忆管理页，查看此前累积的知识盲区，针对盲区一键生成 Quiz，答错的题目继续回写盲区，形成闭环。

## 4. 界面设计说明

> 本节仅描述结构与交互流程，不含前端代码。整体为三栏桌面布局，本地静态资源，不依赖 CDN。

### 4.1 主界面（问答 / 学习工作台）

```
┌───────────────┬──────────────────────────────────────┬──────────────────┐
│ 左栏           │ 中栏 · 对话区                          │ 右栏             │
│               │                                      │                  │
│ [＋ 上传资料]  │  当前材料：高数-第3章.pdf（第 12 页）    │ 引用面板          │
│               │  ┌────────────────────────────────┐  │ ────────────     │
│ 资料库 ▾       │  │ 我：这一节的核心结论是什么？      │  │ [1] 第3章.pdf     │
│  · 高数-第3章  │  └────────────────────────────────┘  │     p.12 ¶2       │
│  · 论文A.pdf   │  ┌────────────────────────────────┐  │ [2] 第3章.pdf     │
│  · 课件.pptx   │  │ AI：材料中给出了…… [1][2]        │  │     p.14 图3      │
│               │  │     （点击角标跳转原文）          │  │ （点击→中栏定位）  │
│ 会话列表 ▾     │  └────────────────────────────────┘  │                  │
│  · 期末速成    │                                      │ 记忆面板          │
│  · 论文精读    │  [🎙 按住说话] [引导式学习 ●] [发送]  │ ────────────     │
│               │                                      │ · 偏好：要例证    │
│               │                                      │ · 盲区：极限定义  │
│               │                                      │ [管理记忆 →]      │
└───────────────┴──────────────────────────────────────┴──────────────────┘
```

交互流程：左栏选材料/会话 → 中栏对话（底部语音按钮、引导式开关）→ 回答中的引用角标点击后右栏高亮命中片段并跳回原文 → 右侧常驻显示本次引用来源与当前记忆摘要。

## 5. 关键产品规则（护栏）

以下规则为**产品级硬约束**，由 `00-项目约束与背景.md` 第 5 节质量红线翻译而来，任一违反即整体验收不通过。

1. **密钥安全**：API Key 只存本机配置文件（加密存储），不写入日志、不明文上传、不下发到前端界面；日志中出现的 Key 一律脱敏。
2. **材料不外传授权**：用户上传的文档默认只在**用户自己配置的 LLM/嵌入端点**间流转；界面须明确提示"你的材料将发送到你配置的模型服务"；未配置端点时不得静默上传到任何第三方。
3. **本机自洽**：核心功能（解析、检索、问答、生成、记忆、语音识别）必须在本机运行，不依赖任何开发者自建服务器。
4. **引用真实性与材料边界**：引用页码/章节必须来自真实解析结果，不得伪造；凡答案中出现材料之外的内容，必须显式标注"材料中未提及"或"（材料外补充）"，不得把材料外内容伪装成材料内引用。
5. **记忆可删除**：长期记忆必须可查看、编辑、删除；**删除后必须同步从召回索引移除**，后续对话不得再召回该条。
6. **模型可切换**：用户必须能自由切换自己的 API 端点 / 模型 / 本地模型（Ollama 等），不被锁定到唯一供应商。
7. **离线可用**：断网后，切换到本地模型模式必须仍可完成问答与检索；本地 ASR 必须离线可用。
8. **构建与启动**：构建必须成功；干净 Windows 环境解压后双击必须能启动，不得要求用户预装 Python / Node / Docker。
9. **引导式教学不可退化为直接作答**：引导模式下首轮不得输出最终答案；若模型输出违反此规则，由产品层拦截并重新生成。
10. **数据本机**：所有数据（资料、切片、向量、会话、记忆、配置）存于本机文件，支持整包迁移与备份恢复。

## 6. 待确认问题

> 仅列需要用户拍板的**非技术**问题；技术实现问题不在本文档提出。

1. **引导式教学的适用范围**：第 5 节规则 9 要求"首轮不给答案"——是**全局默认**对所有问答生效，还是**仅在打开"引导式学习"开关时**生效？（影响默认交互体验，需用户定界。）
2. **资料库组织方式**：采用**单一资料库**，还是支持按"课程/科目"**分组管理**？（影响信息架构与左栏设计。）
3. **数据存放位置**：程序数据默认放在**程序目录内**（拷走整包即可迁移）还是**用户目录**（如 `%APPDATA%`）？是否需要允许用户自定义路径？（影响绿色包的"便携"体验。）
4. **更新方式**：是否需要应用内"检查更新"能力，还是采用**手动替换压缩包**的方式？（影响是否引入联网更新模块。）
