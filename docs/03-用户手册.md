# 知伴 · 用户手册

本手册面向日常使用者。管理员/运维内容（模型切换、日志、备份、升级）见《管理员手册》。

---

## 0. 首次配置：填写 API（必读）

打开软件后**先不要急着提问**，先到「设置 → 对话模型」把两项填全：

| 字段 | 说明 |
|---|---|
| **base_url** | 服务商的 OpenAI 兼容地址，如 `https://api.siliconflow.cn/v1`。点「快速填充」可直接选常用服务商；**选不到你的服务商就选「自定义（手动填写）」**，然后把地址粘进输入框（任何 OpenAI 兼容端点都能直接手填，不必先选预设） |
| **模型名** | ⚠️ **必须填**，如 `deepseek-chat`、`Qwen/Qwen2.5-7B-Instruct`。不知道填什么就点 **「拉取可用模型」**，从端点返回的列表里点选 |
| **API Key** | 服务商控制台生成，本地加密存储，不会写进日志、也不会显示在界面上 |

填好后点 **「测试连接」**。三种结果的应对：

| 提示 | 含义 |
|---|---|
| ✅ 连接成功 | 配置可用 |
| ✅ 连接成功 · ⚠️ 模型名「X」不在可用列表里 | 地址和 Key 没问题，**但模型名写错了**，用「拉取可用模型」重选 |
| ❌ 鉴权失败（HTTP 401/403） | Key 无效、过期或没有该模型权限 |

> **右上角的状态标签是权威判据**：
> - 显示**模型名** = 配置完整，可以提问
> - 显示 **「缺模型名」** = 地址填了但模型名是空的（这是最常见的半配置状态，点标签可直接跳到设置页）
> - 显示 **「未配置模型」** = 地址和模型名都还是空的
>
> 只填了 base_url 时「测试连接」也可能显示成功（因为它只探测端点是否可达），但**没有模型名就无法提问**。

**嵌入模型（语义检索）** 不是必填：不配也能用，会自动退化为本地关键词检索。填了能让你用大白话提问也搜得到。`base_url` 留空 = 沿用对话模型的地址，Key 留空 = 沿用对话模型的 Key。

⚠️ 如果**换过嵌入模型**，旧文档需要用新模型重建索引：到工作台左栏把鼠标移到文档上，点 **↻**。

## 1. 界面总览

启动后共 6 个页面（顶部导航切换）：

| 页面 | 用途 |
|---|---|
| **课程** | 把资料变成一门课：生成大纲 → 确认结构 → 逐节学习与练习 |
| **工作台** | 上传资料、提问、看引用、语音输入 |
| **资料生成** | 生成速查表 / 笔记 / 思维导图 / 练习题 / 闪卡，并导出 |
| **闪卡复习** | 逐张翻面复习，"忘记了"会自动记入知识盲区 |
| **记忆** | 查看与编辑 AI 记住的你的偏好、进度、盲区 |
| **设置** | 配置模型与 API、语音 |

工作台是三栏布局：左栏资料库与会话，中间对话区，右栏引用来源与记忆摘要。

## 1.1 课程（把资料学成一门课）

**创建课程**：课程页 → **＋ 新建课程** → 选材料、写「学完想做到什么」→ 选基础 / 深度 / 单元数
→ 生成大纲（界面会显示生成阶段）→ 进入**结构确认**。

**结构确认页**：左侧改单元/讲次标题与学习目标、增删讲次；右侧是同一份结构的**思维导图**，
改完即时同步。确认后课程就绪。之后随时可在课程详情点**编辑结构**回来改。

**课堂页**（点某一节的「开始」）有四个页签：

| 页签 | 用途 |
|---|---|
| **课件** | 上课用：逐页幻灯片（标题 + 短要点），讲授时按进度一页页出现；没上课时也可以整份翻看 |
| **讲义** | 课后复习用：完整的白板讲义（概念 / 例子 / 公式 / 材料原文 / 补充卡片，加要点、关键术语、回顾） |
| **材料标注** | 打开材料原页，选「高亮」或「圈注」在页面上拖一下即可标注；右侧写旁注，会自动连一条弧线指向对应位置。标注随课程保存 |
| **单元总结** | 学完单元后生成：已掌握 / 待巩固 / 下一步，并给出本单元练习统计 |

课件与讲师讲稿是**两份独立内容**：课件是学生看的短要点；**讲师讲述**区显示的是讲师实际
在讲的话——围绕当前页课件展开解释、举例与衔接，**朗读的正是这份讲稿，而不是课件文字本身**。
生成讲义时系统会同时产出课件与讲稿（每页一一对应）；高级用户也可通过
`PUT /api/courses/lessons/{id}/courseware` 接口单独编辑二者。

> **系统会强制「讲稿不许照念课件」**：生成后用文本相似度做结构判定，一旦发现某页讲稿只是把
> 课件文字念了一遍，就先让模型重写这几页；仍不改口则自动扩写成口语化讲解
> （在 `scripts[].cue` 上标记 `rewritten` / `expanded`，便于排查）。这条不依赖提示词，模型再弱也拦得住。

### 上课时屏幕中下方的「字幕 + 互动」

点 **▶ 开始上课** 后，屏幕**中下方**会常驻两样东西：

| 元素 | 说明 |
|---|---|
| **字幕** | 与语音逐句同步显示讲师正在讲的话，**默认开启、不提供关闭入口**——不方便开声音（图书馆、深夜）时直接读字幕即可 |
| **互动选择** | 每讲完 2 页自动停下，在字幕正上方弹出「听到这里，还好吗？」＋ **继续上课 / 重讲本页 / 我有疑问 / 不用停，直接讲完** |

互动选择之所以放在屏幕中下方而不是右上角，是因为上课时视线在课件与语音上，放右栏角落很难被发现。

课堂页顶部有一条**吸顶操作条**，讲义再长也不会被冲走：

| 位置 | 内容 |
|---|---|
| 最左 | **← 返回课程**（符合从左往右的返回习惯） |
| 右侧（上课中） | **⏸ 暂停 / ▶ 继续** —— 随时暂停朗读再接着讲，不用停止重讲 |
| 次左 | **第 X 单元 · 第 Y 课 / 本单元共 N 课**，一眼知道学到哪了 |
| 右侧 | ▶ 开始上课 / 重新生成讲义 / 导出图片 / 导出讲义 / 导出对话 / 跳过本节课，进入下一节 |

右侧**课堂提问**：

- **默认按「开放回答」处理** —— 既用你的材料，也允许围绕你的疑问补充材料之外的知识；
  用到材料外内容时会在回答开头标注「（材料外回答，未基于当前材料）」，方便你分辨。
  （工作台的提问默认仍是严格模式：材料没提到就如实说「材料中未提及」，可在那里勾选「允许材料外回答」。）
- 提问会自动带上「当前课件第 n 页」的上下文，所以「linux 系统也是一样吗」这类指代也能被理解；
- 回答里带页码引用时，点引用可直接跳到材料对应页。

右侧**讲师讲述**区会按页保留全部讲稿，可以往上翻回看。

**上课中切到别的页面不会中断**：去闪卡复习、记忆、设置再回来，课堂会停在你刚才听到的那一页
继续讲；此时屏幕左下角会出现 **「● 正在上《…》 · 回到课堂」** 浮动按钮，点它直接回到课堂。
（若离开期间朗读被打断，回到课堂会从当前页自动续讲。）

**选课界面会标出接下来要上的那一讲**：已学完的讲次保持普通样式，
第一个未完成的讲次会高亮并带「接下来」徽标，按钮也变成主色，一眼就能看出该上哪一节。

课件区左右各留出一列（与右侧栏同宽），**课件因此在屏幕中间显示**，不再贴着最左边。

**随堂练习（讲完自动开始）**：一讲讲完就**自动生成 5 道随堂测验并进入答题**，不用再手动点。

- 题型**以单选为主**（5 题时通常 3~4 道单选，判断/填空/开放各至多 1 道），部分题会带材料页配图；
- **每答完一题立刻显示对错 + 参考答案 + 解析**，随后才允许进入下一题；
- **未作答时「下一题」是禁用的**，不能跳过题目；

  > 选择题点选项即判定（判定后选项锁定，正确项标绿、选错项标红）；填空与开放题需要点
  > 「✅ 确认作答」或按 Enter。

- 全部答完提交后显示总分、正确率与逐题解析；错题记入课程错题本，可「再做一次」。

**进度**：课程页显示整体进度与每个单元的练习成绩；课程详情可看每单元统计。

### 课件页都有哪些「形态」

一讲的课件不再是清一色的要点页，AI 会**按内容形态**挑合适的页型：

| 页型 | 什么时候出现 | 你会看到什么 |
|---|---|---|
| 要点页 | 概念、例子、公式、材料原文、补充 | 短标题 + 最多 5 条要点（关键术语会**加粗**） |
| **对比表格页** | 两个/多个方案、编码、观点的**逐项对照** | 一张表格（如上例的 936 vs 65001） |
| 图示页 | 流程、步骤、因果、结构关系 | Mermaid 流程图/时序图 |
| 图表页 | 材料里有能成图的**数值**对比 | 柱状 / 折线 / 饼图 |
| **金句卡** | 讲末收尾 | 一句大字号结论/点评 |

两侧都有护栏：提示词限制「每讲可视化页（表格/图示/图表）最多 2 页、金句卡最多 1 张」，
服务端再校验一次（表格列数/行数、图表数值、图示语法），**不合格的页自动退化成普通要点页**，
所以你不会遇到空白页或画歪的图。

### 上课时的自动滚动与暂停

- 翻到新的一页课件时，页面会**自动把这一页滚到顶部**，从标题开始完整显示，
  不会再出现「上半页被底部字幕条压住、要手动往下拉」的情况；长页面往下翻时，
  结尾也留了余量。
- 想中途停下：点操作条的 **⏸ 暂停**；继续时点 **▶ 继续**，或者**直接点字幕条任意位置**都能接着讲。

### 学习目标让 AI 帮你推荐

创建向导里点 **✨ 帮我推荐**，程序会**按你勾选的材料**给出 4 个「学完能做到什么」的目标，
点一下即可填入。推荐结果下方会写明 **「推荐基于你勾选的：…」**，
方便你一眼确认它读的是不是你想要的那份材料。

### 实操题与「实践环节」开关

有些课程适合真的动手（比如命令行、软件操作），有些完全不适合（比如文言文、纯理论）。
所以创建向导里多了一项 **「实践环节」**：

| 选项 | 效果 |
|---|---|
| 包含实操（默认） | 随堂练习里可能出现 **🖐 实操题**：题干要求你真的去操作一次（如「打开 CMD 输入 chcp 并回车，把你看到的编号填进来」），再把结果填进输入框，判分和填空题一样（不区分大小写与标点，可接受多种等价写法） |
| 纯理论 | 出题**不会**出现实操题；讲稿也不允许布置「打开终端试试」这类操作任务 |

一门课建好后该开关不再改动（要改可以重新建课）。

## 2. 上传资料

1. 工作台左栏 → **＋ 上传**
2. 选择一个或多个文件（支持 PDF / DOCX / PPTX / MD / TXT / 网页）
3. 等状态从"parsing"变成页码数字（表示解析完成）

- **点一下条目 = 选中/取消选中**，选中的材料会高亮。选中的话，提问只在所选材料里检索。
- **↻ = 重新解析**：用当前嵌入模型重建该文档的切片与向量索引。**换过嵌入模型后必须点它**，否则新旧向量不在同一个语义空间，检索会不准。重新解析前会先清空旧切片，不会重复累积。
- **✕ = 删除**该文档，其切片与索引一并删除。
- 鼠标悬停可看到完整文件名；若文件是扫描版（纯图片 PDF），会提示"无可提取文本层"。

> 建议：期末复习时把整学期的 PPT 一次性传上来，然后在「资料生成」里选全部 → 生成速查表。

### 上传之后可以直接这样问

材料一旦上传并选中，下面这类"关于材料本身"的问题**不需要你把内容复制进对话框**，知伴会自己去读材料：

- `看下 学习好文.txt 的具体内容，然后安排学习`（点出文件名即可）
- `帮我总结一下这篇文档`
- `开始学习` / `这份资料的重点是什么` / `帮我列个学习大纲`

原理：这类问题与材料正文没有共同词汇，普通关键词检索会扑空。此时系统会自动注入一份**材料概览**（文件名 + 章节结构 + 开头内容），让模型先掌握材料范围再回答。

反过来，问**材料里没有的知识点**时，知伴仍会如实回答"材料中未提及"并给出零引用，不会拿概览去编造答案。

## 3. 提问与引用

在输入框输入问题，**Enter 发送**（Shift+Enter 换行）。

回答中的 **[1] [2]** 是引用角标：

- 回答下方与右栏会列出**紧凑的引用卡片**（只显示出处 + 一小段摘要，不会把整段正文糊在对话里）
- 点引用卡片 → 在**当前窗口内弹出浮层**显示原文片段（页码 / 章节 / 原文摘录），不会再弹出新窗口
- 页码来自你上传的文档本身，不是模型生成的

**两个开关（输入框下方）**：

| 开关 | 作用 |
|---|---|
| 🎓 **引导式学习** | 打开后，AI **不直接给答案**，而是先追问你的思路、把问题拆成几步，引导你自己想明白。适合真正想学会的场景 |
| **允许材料外回答** | 默认关：材料里没有的，如实回"材料中未提及"。打开后：AI 会用通用知识回答，但会标注"（材料外回答，未基于当前材料）" |

**建议的使用节奏**：

- 平时查概念 → 关闭引导式（直接给答案，快）
- 真正想学会一个难点 → 打开引导式，跟着追问走

**引导式回答下面那个蓝色小框是什么？**

- **🎯 请先回答** —— 这是**本轮要你回答的问题**，是唯一需要你行动的东西，直接回复即可。
- **引导详情（拆解步骤 · 教学状态）** —— 默认**折叠**。里面是 AI 的拆解步骤与内部教学状态
  （`explain`/`probe`/`evaluate`），拆解步骤 AI 在正文里通常已经讲过，所以平时不用展开；
  想自省或排查问题时可以点开看（"来源"能看出本轮是模型正常输出还是系统的兜底模板）。

> 简单说：**只看「请先回答」就够了**。

## 4. 语音输入（本地识别，断网可用）

1. 点输入框左侧 **🎙 按住说话**
2. 浏览器第一次会请求麦克风权限，选"允许"
3. 说完点 **⏹ 结束录音**，识别结果自动填进输入框，确认无误后发送

- 识别在**本机完成**，音频不会上传到任何地方
- 模型已随软件附带，无需联网

## 5. 朗读（可选，默认关闭）

1. **设置 → 语音**：朗读模式选「本地系统语音（离线，用 Windows 自带音色）」→ **保存语音设置**
2. 回工作台，勾选底部 **🔊 朗读**

勾上之后，**每一条新回答都会自动朗读**（不是只读一次）。

**没声音怎么办**：到 **设置 → 语音** 点 **🔊 试听**，它会告诉你
- 本机共有几个语音音色、实际用的是哪一个；
- 若显示「未找到中文音色」，说明 Windows 缺中文语音包 → 到「Windows 设置 → 时间和语言 → 语音」添加中文语音，或改用云端朗读。

朗读时会自动去掉引用角标、代码块与 Markdown 符号，只读出内容本身。

默认关闭。到 **设置 → 语音 → 朗读** 开启：

> **云端朗读的 Key 要不要单独申请？** 看站点：
> - **语音服务和对话模型是同一个站点** → **不用申请第二个 Key**，端点与 Key 两栏都留空即可，
>   程序会自动沿用对话模型的地址与 Key（同一个平台的一个 Key 通常对所有接口通用）。
> - **语音服务是另一家** → 必须填那家的**端点**和**那家自己的 Key**。
>   这时即使你留空 Key 栏，程序**也不会**把对话模型的 Key 发过去（避免把 A 站的密钥泄露给 B 站），
>   而是直接报错提示你补填。

| 方式 | 说明 |
|---|---|
| **本地系统语音** | 用 Windows 自带中文音色（如 Microsoft Huihui），离线、零配置。开启后工作台底部会出现"🔊 朗读"开关 |
| **本地神经语音（MeloTTS）** | 更自然的离线合成音色，中英混读。模型已随包内置（约 52MB），零外发、零配置；在设置页把本地引擎选为「神经语音 MeloTTS」即可 |
| **云端 API** | 音色最自然，需填一个语音服务的 base_url / 模型名（**这两项是必填的**）。Key 与对话模型**独立**：同一站点时可留空，程序自动沿用对话模型的地址与 Key；**换成别的站点**才需要填该站点自己的 Key。**选这个模式后务必点一次「测试连接」**，能用了再上课/开朗读 |

语音区最下面一行会实时显示 **「当前生效：…」**（云端朗读 / 本地神经语音 MeloTTS / Windows 系统语音 / 已关闭），
一眼就知道真正在用的是哪个引擎。旁边三个按钮的分工：

| 按钮 | 作用 |
|---|---|
| **测试连接** | 给语音端点发一个极短的合成请求，只回报告状态，不播声音。**先点它** |
| **🔊 试听** | 真合成一句话并**播放出来**（三种模式都支持：系统语音 / MeloTTS / 云端） |
| **保存语音设置** | 存盘并**立即生效**，不用重开软件 |

### 云端朗读没声音？按这个顺序查

两个按钮都会把**失败的真实原因**直接写在按钮右边，不会再「悄悄换成系统语音」——
以前云端配置错了会静默降级成本地朗读，让人分不清是填错了还是软件坏了，现在不会了：

1. **点「测试连接」**：
   - 显示 `✅ HTTP 200：<地址>/audio/speech 可用` → 配置没问题；
   - 显示 `❌ …未配置…` → 语音端点和模型名还是空的；
   - 显示 `❌ …HTTP 401/403` → **Key 不对或没有权限**（该站点不认这个 Key）；
   - 显示 `❌ …HTTP 404` → **地址填错了**，或者该站点不提供 `/audio/speech` 接口；
   - 显示 `❌ …ConnectError / 超时` → 地址不可达（拼错、或本机网络/代理问题）。
2. **点「🔊 试听」**：结果里会同时给出 HTTP 状态、音频格式、字节数、耗时，
   以及最关键的一行 **「实际请求：http://…/audio/speech」**。
   **照着这一行核对**——很多人是把「接口地址」和「完整请求地址」搞混了：
   如果这行里出现了 `/chat/completions` 之类的内容，说明地址填成了某个具体接口而不是服务根地址。
3. 仍然无声但两个按钮都显示成功 → 问题在播放端（系统音量、浏览器自动播放限制），不是配置。

### 音色（voice）——非 OpenAI 服务商最容易踩的坑

`alloy` / `echo` / `nova` / `shimmer` 这些是 **OpenAI 的音色名**，只有 OpenAI 系的服务商认。
换成别家（如阶跃星辰 StepFun）就会返回 `HTTP 400：The voice_id (alloy) does not exist`。
所以语音区专门留了 **「音色 voice」** 一栏：**留空时程序会兜底用 `alloy`**，
如果你用的不是 OpenAI 系服务商，就得填**该服务商自己的音色名**。

填错也不会瞎猜：连接测试和试听会把上游那句原始报错原样显示出来，
并且检测到是音色问题时直接提示你去改这一栏。

> **实测可用的例子**（阶跃星辰 StepFun `stepaudio-2.5-tts`，2026-09-14 逐个验证）：
> `cixingnansheng`（磁性男声）、`shenchennanyin`（深沉男音）、`qingniandaxuesheng`（青年大学生）、
> `qinqienvsheng`（亲切女声）、`wenrounvsheng`（温柔女声）、`ruanmengnvsheng`（软萌女声）、
> `jilingshaonv`（机灵少女）、`yuanqishaonv`（元气少女）。
> 换成别的服务商时，到该服务商的文档里找它的 `voice` 取值即可。

## 6. 生成复习材料

进入 **资料生成**：

1. 勾选来源材料（可多选）
2. 选类型：速查表 / 学习笔记 / 思维导图 / 练习题 / 闪卡
3. 选篇幅（精简 / 标准 / 详尽），题类可设数量
4. **开始生成** → 预览 → **导出 ▾**

导出能力：

| 类型 | 可导出为 |
|---|---|
| 闪卡 | **Anki (.apkg)** / Markdown / CSV |
| 练习题 | Anki (.apkg) / Markdown / CSV |
| 思维导图 | Markdown / **PNG 图片** |
| 速查表 / 笔记 | Markdown |

> 思维导图卡片右上角有"导出图片"按钮；闪卡可在预览时**点击翻面**。

## 7. 闪卡复习

进入 **闪卡复习**：

1. 选择卡组（按生成批次）或"全部闪卡"；可勾选"只看到期的"
2. 点卡片**翻面**看答案
3. 如实点 **记住了 / 有点模糊 / 忘记了 / 很简单** —— 系统按 SM-2 间隔重复算法安排下次复习时间
4. **点"忘记了"会把该知识点写入知识盲区**，之后可在「记忆」页查看，针对性补强

## 8. 记忆

AI 会跨会话记住你的**偏好**（如"讲解要配例证"）、**学习进度**、**知识盲区**。

- **记忆页**可以：查看 / 编辑 / 新增 / 删除 / 导出 / 清空
- **删除是物理删除**：该条目会同时从检索索引与向量库中移除，之后的对话**不会再召回**它
- 右栏"记忆"面板显示最近生效的记忆，点"管理"跳转
