# 啃书先生 · 模型兼容列表

啃书先生通过 **OpenAI 兼容协议**（`/v1/chat/completions` + `/v1/embeddings`）接入模型，
因此凡是实现该协议的端点都可以用。以下为**在本机实测验证**与**按协议应可工作**的清单。

标注说明：✅ = 本机实测通过；🧪 = 协议兼容、按文档应可用（未逐一实测）；
❌ = 已知不可用/需要特殊处理。

## 4. 语音

### 4.1 语音识别（ASR）— 固定本地，不提供云端选项

| 项 | 值 |
|---|---|
| 引擎 | **sherpa-onnx 1.13.8**（进程内 ONNX 推理） |
| 模型 | **SenseVoice-Small int8**（`model.int8.onnx` ≈ 228MB + `tokens.txt`） |
| 语言 | 中文为主，兼英/日/韩/粤 |
| 网络 | **零外发请求**（红线，测试有断言） |
| 实测 | 中文音频转写准确（"思维导图可以帮助我们建立知识框架…" 全对） |

模型来源（构建/补装时自动下载）：
`https://hf-mirror.com/csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17`
（HuggingFace 国内镜像；GitHub Release 直连在国内网络下不可用，故不采用。）

### 4.2 语音合成（TTS）— 可选，三态

| 方式 | 依赖 | 网络 | 状态 |
|---|---|---|---|
| **关闭**（默认） | — | — | ✅ |
| **本地系统语音** | 浏览器 `SpeechSynthesis`（Windows 自带 SAPI） | 离线，零 Key | ✅ 本机实测有中文音色 `Microsoft Huihui (zh-CN)` |
| **云端 API** | OpenAI 兼容 `/audio/speech`（SiliconFlow / OpenAI 等） | 需网络 | 🧪 Key 与对话模型分开配置 |

## 6. 明确不支持 / 已知限制

- ❌ 非兼容协议的端点（如部分厂商原生 SDK 协议）——请使用其"OpenAI 兼容"入口
- ❌ 云端 ASR（产品定位决定：学生语音**只在本机处理**）
- ⚠️ `response_format=json_object` 不支持的端点：会自动降级为"提示词约束 + 文本提取"，
  引导式教学的结构化输出稳定性略降（护栏仍会兜底，不影响"首轮不给答案"这条硬规则）
- ⚠️ 扫描版 PDF 不做 OCR
